About ranking

APIs are ranked within each group by the number of papers that use them directly, then by direct theorem uses. Filtering keeps the original ranks. Theorems / Papers counts all related theorem statements and the distinct papers containing them, including direct and indirect dependencies. Each theorem and paper is counted once.

  • Green — Use mathlib: an existing interface or direct composition of existing operations suffices, with matching mathematical meaning, domains and assumptions.
  • Yellow — Small adaptation: the core mathematics exists; a thin wrapper, representation conversion or local connecting proof remains.
  • Red — New infrastructure: an essential construction, core property or reusable theory required by this interface needs development.

The boundary is missing mathematical content, not code length or the absence of a same-name API. Assessments concern the archived interface and its variants, not proofs of every related paper theorem. They are planning estimates from the recorded audit evidence.
